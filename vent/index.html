Vent Lab is an educational simulator built on a single-compartment model of the respiratory system. The console layout and parameter set follow modern ICU ventilators (Nihon Kohden NKV-550 numerics, a Hamilton-style dynamic lung); it is not a copy of any manufacturer's software. Numbers are teaching approximations, not predictions for a real patient. Do not use it to guide patient care.
